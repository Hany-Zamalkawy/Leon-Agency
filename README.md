# Leon — Creative Digital Agency Template

A modern, responsive one-page HTML/CSS/JS template for a creative digital agency, inspired by the **Leon PSD Agency** design. Built with plain HTML, CSS and vanilla JavaScript — no frameworks or build tools required.

## Preview

Open `index.html` in any browser to view the live template, or enable **GitHub Pages** (see below) to view it online.

## Features

- 🎨 Clean, modern design with a dark navy (`#2C4755`) and teal (`#10CAB7`) color palette
- 📱 Fully responsive — works on desktop, tablet, and mobile
- 🧭 Sticky navigation bar with scroll-based styling and mobile menu toggle
- 🚀 Hero section with animated floating stat cards
- 🏢 Client / brands logo strip
- 📖 About section with checklist and stats badge
- 🛠️ Services grid with hover interactions
- 🖼️ Filterable portfolio grid (All / Branding / Web Design / App / Marketing)
- 👥 Team members section
- 💬 Testimonials section
- 📣 Call-to-action banner
- 🔗 Footer with newsletter signup and social links
- ⬆️ "Back to top" button
- ✨ Scroll-reveal animations using `IntersectionObserver`

## Tech Stack

- HTML5
- CSS3 (custom properties / variables, Flexbox, Grid)
- Vanilla JavaScript (no dependencies)
- [Google Fonts](https://fonts.google.com/) — Poppins & Inter
- Placeholder images via [Picsum Photos](https://picsum.photos/)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/USERNAME/leon-agency-template.git
   ```
2. Open `index.html` in your browser — that's it, no build step needed.

## Customization

- **Colors:** edit the CSS variables at the top of the `<style>` block (`:root { --dark; --teal; ... }`).
- **Content:** replace the placeholder text and images (`picsum.photos` URLs) with your own copy and assets.
- **Sections:** each section is clearly commented in `index.html` (`<!-- HERO -->`, `<!-- SERVICES -->`, etc.) for easy editing.

## Deploy with GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and `/ (root)` folder.
4. Save — your site will be live at `https://USERNAME.github.io/leon-agency-template/`.
